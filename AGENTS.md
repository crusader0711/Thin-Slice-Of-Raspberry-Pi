# AGENTS.md — canonical AI-agent context

**Tier:** T1 (public/released) per OFS-EN repo template v1.0
**Project:** Zero-touch Raspberry Pi thin-client kiosks for children, backed by
self-hosted Kasm Workspaces on UNRAID. Read `README.md` for architecture,
`BUILD.md` for the linear build procedure, `docs/decisions/` for immutable
design history.

## Commands (all verified)

- `make help` — list targets
- `make setup` — dev deps + installs git hooks (`core.hooksPath hooks/`)
- `make lint` — `bash -n` + shellcheck (if present) + placeholder-hygiene scan
- `make test` — unit suite in `tests/unit/` (mocked launcher/API tests)
- `make build` — tarball of `src/pi` + config example into `dist/`
- `make release` — build + generate `RELEASE_MANIFEST.json` + `SHA256SUMS`

## Layout

- `src/pi/` — the deployable client: `provision.sh` (idempotent), `kiosk.service`,
  `kiosk-browser.sh`, `get-login-url.sh`, `wait-for-kasm.sh`
- `docs/` — walkthroughs (`01-`, `02-`, `03-user-guide`), `architecture.md`,
  `decisions/` (ADRs — never edit an Accepted ADR; supersede it),
  `runbooks/` (troubleshooting = F1–F11 acceptance matrix)
- `tests/unit/` mirrors `src/` behavior; integration = hardware-in-the-loop,
  manual, documented in `tests/integration/README.md`

## Guardrails

1. **Never commit concrete IPs, hostnames, casting keys, or API credentials.**
   Use `<PLACEHOLDERS>`; `make lint` and the pre-commit hook enforce this.
2. **Human-authored content carries no dates** except the README Last Updated
   badge. Machine-generated release artifacts (`RELEASE_MANIFEST.json`) carry
   ISO timestamps by template requirement — that is the sole exception.
3. ADRs in `docs/decisions/` are immutable once Accepted — write a new one.
4. Shell must pass `bash -n` and the unit suite before commit.
5. `RELEASE_MANIFEST.json` and `SHA256SUMS` are generated by `make release`,
   never hand-edited.
6. Child-safety posture is architectural: filtering stays server-side; do not
   add client-side filtering or move policy onto the Pi.
7. Backlog SoT is `docs/BACKLOG.md` (IDs `BL.NN`, never reused); idea text must pass the PII/hygiene rules.
