# 03 — User Guide (for the family)

*Print this page and tape it near the kiosk if you like.*

## Using the computer

1. **Turn it on** — press the power button (or plug it in).
2. **Wait** — the screen may be black or show a spinner for up to a minute
   while it connects. No clicking needed.
3. **Use it** — the browser appears by itself. Click, type, watch, play.
4. **Done?** Just turn it off (switch/unplug). Your bookmarks and saved
   things are kept safe on the family server automatically.

## Things that are normal

- **Your stuff comes back.** Bookmarks and saved things live on the family
  server, so they survive turning the kiosk off — even if the screen said the
  session ended.
- **Open tabs *usually* come back** if you return soon; after a long time away
  the computer starts a fresh page, but your bookmarks are all still there.
- **Some websites are blocked.** A block page means the filter is working, not
  that something is broken.
- **If it sits unused for a while, the session ends.** Turning the kiosk off and
  on brings back a fresh one.

## If something looks wrong

| Symptom | Do this |
|---|---|
| Frozen screen or weird error | Turn it off, wait 10 seconds, turn it on |
| Still broken after a restart | The *server* may be off — tell the adult who runs it |
| No sound | Check the monitor/speaker volume first; then restart the kiosk |

**The one fix that solves almost everything: turn it off and back on.**
Everything important is saved on the server, so a restart never loses it.

## For the adult on duty

- The kiosk is a dumb screen; the actual "computer" runs on the home server.
  If the server or its Kasm container is stopped, every kiosk shows a
  connection error until it's back.
- Screen-time limits, allowed websites, and filtering are all controlled in the
  Kasm admin page on the server — never on the kiosk itself.
- The kiosk reboots itself every night at 4 a.m. to stay fresh.
